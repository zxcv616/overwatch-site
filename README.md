# Overwatch project website

Static portfolio for an aerial object detection experiment.

## Cloudflare Pages

- Production branch: `main`
- Framework preset: None
- Build command: leave empty
- Build output directory: `dist`
- No functions, paid services, or environment variables required.

Local preview: `python3 -m http.server 8765 --directory dist`

Dataset imagery: [VisDrone](https://github.com/VisDrone/VisDrone-Dataset). Results and limitations are downloadable from the site.
