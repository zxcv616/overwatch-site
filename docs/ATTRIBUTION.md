# Attribution and reuse

[← Project overview](../README.md)

## Dataset

The aerial photographs, bounding-box annotations, and derivative comparison images use the **VisDrone2019 detection dataset**. Dataset examples are included to explain the experiment, not as original photography.

- [VisDrone dataset repository and usage terms](https://github.com/VisDrone/VisDrone-Dataset)
- [VisDrone project](https://www.visdrone.org/)

Dataset material remains subject to its original terms. Public availability of this repository does not grant new rights to third-party imagery or annotations.

## Tools

- [Ultralytics YOLO](https://github.com/ultralytics/ultralytics): pretrained detector and fine-tuning framework.
- [PyTorch](https://pytorch.org/): model training and inference.
- [COCO API / pycocotools](https://github.com/cocodataset/cocoapi): explicit detection scoring.
- [Matplotlib](https://matplotlib.org/) and [Pillow](https://python-pillow.org/): analysis plots and annotated gallery images.
- [Google Colab](https://colab.research.google.com/): training and evaluation compute.
- [Cloudflare Pages](https://pages.cloudflare.com/): static website hosting.

The website loads DM Sans and Space Grotesk through Google Fonts. Each upstream project retains its own license and terms. No blanket license for third-party material is implied.
